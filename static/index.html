      Acerca del Proyecto

      ForensysLab v2.0 — Laboratorio Forense Digital

      ForensysLab v2.0 es un sistema de inteligencia forense digital desarrollado como proyecto de grado. Integra análisis dactilar, un motor de predicción estadística de conductas delictivas, gestión de base de datos de sospechosos e IA.

      • OpenCV + LBPH Facial Recognition
      • SQLAlchemy + SQLite
      • Scikit-learn (Predicción)
      • HTML5 / CSS3 / JavaScript

      Funcionalidades

      • Reconocimiento facial en vivo
      • Gestión CRUD de sospechosos
      • Captura de foto con webcam
      • Algoritmo predictivo forense
      • Autenticación con roles
