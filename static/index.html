      Acerca del Proyecto

      ForenSys Lab V1 — Laboratorio Forense Digital

      ForenSys Lab V1 es un sistema de inteligencia forense digital desarrollado como proyecto de grado. Integra análisis dactilar, un motor de predicción estadística de conductas delictivas, gestión de base de datos de sospechosos e IA.

      • HTML5 / CSS3 / JavaScript

      • Reconocimiento facial en vivo
      • Gestión CRUD de sospechosos
      • Captura de foto con webcam
      • Algoritmo predictivo forense
      • Autenticación con roles
